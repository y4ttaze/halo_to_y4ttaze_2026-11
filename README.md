# サークル「波呂とy4ttaze」デジタルお品書き

ボカスト（ボーカロイドストリート）に向けたデジタルお品書きの特設サイトです。

## 🌐 公開URL
- **Webサイト**: https://[あなたのGitHubユーザー名].github.io/[あなたのリポジトリ名]/
*(※GitHub Pagesの設定完了後、実際のURLに書き換えてください。カスタムドメインを使用する場合はそのドメインを記載してください)*

## 🛠️ ローカル開発環境の動かし方
Pythonがインストールされている環境で、以下のコマンドを実行するとローカルサーバーが立ち上がります。

```bash
# サーバー起動
python3 -m http.server 8000
```
起動後、ブラウザで `http://localhost:8000` にアクセスしてください。
